# 看板改造方案（v0.21 拟定）

> 状态：方案待确认 · 目标：桌面端看板页重设计，采用环形构成图呈现核心资金指标，并保留「点击银行存款打开流水明细」的既有交互。

## 1. 背景与目标

当前看板（`web/src/features/transaction/Home.vue`）为**资产快览卡片 + 最新流水 + 欠款明细**的纵向布局。本次改造目标是：

- 用**环形构成图（饼图）**替代单调数字，直观呈现四块核心资金的分项构成：
  银行存款、在外投资、待收欠款、可支出。
- 保持轻量简洁、浅色风格，色系经评审调整为「深青蓝 + 琥珀金 + 灰蓝紫」谐和配色（非强制绿）。
- **交互保留**：点击「银行存款」卡片，打开银行流水明细弹窗（沿用老看板既有功能）。

## 2. 数据口径（与业务方确认）

| 指标 | 定义 | 数据来源 |
|---|---|---|
| 银行存款 | `capital.bankBalanceCents`（期初 + Σ收 − Σ支 ± 资金划转） | `GET /api/summary` → `capital` |
| 在外投资 | `capital.assetTotalCents`（长期投资/对外投资收益本金科目合计） | `GET /api/summary` → `capital` |
| 待收欠款 | 往来单位应收未收合计（`/api/receivables?status=open` 求和） | `GET /api/receivables` |
| 可支出 | **仅** 532分配支出科目余额 + 土地流转管理费支出科目余额 | 按科目名动态筛选聚合 |

**资金构成口径**：只计「银行存款 + 长期投资 + **应收收益**」；土地流转费、流转管理费的欠款**不计入**「资金构成」，仅在「欠款构成」中分开展示。
（此口径为评审确认结果，看板 UI 上不展示说明文字。）

### 环形构成图（2×2 布局）

| 板块 | 分项 |
|---|---|
| 资金构成 | 银行存款 · 长期投资 · 应收收益 |
| 在外投资构成 | 长期投资 · 再投资 · 其他 |
| 欠款构成 | 土地流转费 · 流转管理费 · 应收收益 |
| 可支出构成 | 福利费(532) · 流转管理费 |

> 欠款构成与可支出构成的二级科目归属，需在后端按**科目名称**动态解析（禁硬编码科目 ID，因科目 ID 随组织注册变化）。

## 3. 页面布局（自上而下）

```
┌─ 顶栏 ────────────── 标题 · 副时间线 · 「记一笔」按钮
├─ 银行存款主卡 ─────── 独占一行（可点击 → 打开银行流水明细弹窗）
├─ 环形构成 2×2 ─────── 资金构成 | 在外投资构成 | 欠款构成 | 可支出构成
├─ 欠款明细 TOP ─────── 金额降序，到期/临期标色
└─（删除）───────────── 最新流水、月度收支趋势、资产快览四卡
```

- 仅保留 **银行存款** 一张主 KPI 卡；原「在外投资 / 待收欠款 / 净资产」三张副卡移除（其内容由环形图承载）。
- 底部「欠款明细 TOP N」保留（金额降序，到期标红、临期橙色）。

## 4. 关键交互：点击银行存款打开流水明细

**沿用既有实现**（`Home.vue` 中 `openBankFlow()` + `van-popup`），不改变后端接口：

- 点击银行存款主卡 → `openBankFlow()` 打开弹窗。
- 取数逻辑（保留现有）：
  1. `GET /api/settings` 读取银行期初余额 `bankOpeningBalanceCents`；
  2. `GET /api/transactions?pageSize=10000` 取全量流水；
  3. 按 `txnDate` 升序（同日按 `id`），从期初余额起逐笔累加收入/支出，算出每笔结余；
  4. 逆序后**最新在上**展示。
- 弹窗表头：日期 / 收入 / 支出 / 余额。
- 首次打开加载，后续复用内存缓存（`bankFlowRows.value.length > 0` 即不重复请求）。

## 5. 后端改动点（拟定）

在 `server/internal/summary/repo.go` 增加**构成聚合**查询，按科目名分组取四类构成（资金构成须排除土地流转费/流转管理费欠款）。可新增响应字段：

```go
type Composition struct {
    BankDepositCents  int64 `json:"bankDepositCents"`   // 银行存款（复用 capital）
    InvestmentCents   int64 `json:"investmentCents"`    // 在外投资
    ReceivableIncCents int64 `json:"receivableIncCents"` // 应收收益（资金构成口径）
    OweFlowCents      int64 `json:"oweFlowCents"`        // 土地流转费欠款
    OweMgmtCents      int64 `json:"oweMgmtCents"`        // 流转管理费欠款
    Expense532Cents   int64 `json:"expense532Cents"`     // 可支出：532分配
    ExpenseFlowMgmtCents int64 `json:"expenseFlowMgmtCents"` // 可支出：流转管理费
}
```

> 科目按名称动态解析（`internal/category` 提供 name→id 映射），不硬编码 ID。
