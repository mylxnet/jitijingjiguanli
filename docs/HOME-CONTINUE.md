## 三、注意事项（重要）

- **单边修改原则**：这套拷贝方式下，确定一台"主战场"（建议家里）。
  不要"公司改一点、家里改一点"再互相覆盖 —— 会丢改动且难以合并。
- **数据**：家里是全新空库。上线使用前记得：注册你们的组织 → 预置科目自动生成 → 设置银行存款期初。
- **公司电脑的仓库**：保持现状即可。如果某天想结束"拷贝搬运"、改回两地同步协作，
  把本地仓库推到一个 GitHub/Gitee 私有远程只要约 10 分钟（git remote add + push），随时可做。
