# 集体台账 v0.5.0 发布说明

- 版本：**v0.5.0**（大版本定版）
- 形态：Windows x64 单可执行文件（前端已内嵌，无需安装 Go / Node / 数据库）
- 提交线：`349540c → cd22aec(v0.5.0) → 78db618(单 exe) → 1d35547(start.bat)`

## 文件清单（拷贝到任意普通文件夹即可）

| 文件 | 说明 |
|---|---|
| `jititaizhang.exe` | 服务主程序（约 40MB） |
| `start.bat` | 双击启动：自动探测空闲端口（8080 被占则顺延）并打开浏览器 |
| `发布说明.txt / 本说明` | 使用与运维要点 |

## 运行

1. 把 `jititaizhang.exe`、`start.bat` 放到**普通目录**（如 `D:\jizhang`，不要放系统盘受保护目录）
2. 双击 `start.bat`（或直接运行 exe）
3. 浏览器自动打开 `http://localhost:<端口>/`
4. 首次使用：登录页 →「注册组织」→ 填组织名+账号+密码 → 自动生成预置科目

> 服务启动会在同目录自动创建 `data\`（数据库）与 `backups\`（备份）。

## 功能速览（v0.5.0）

- 多组织自助注册、数据完全隔离
- 科目两级：**资产 / 权益**（到账才算收益；无勾稽/期初口径）
- 首页看板：银行 / 资产类 / 待收欠款 / 净资产 + 本年收益到账 + 欠款明细
- 记一笔：普通记账 / 快速记账（10 个业务模板自动入账：补助、收益、流转费冲欠款、服务费、利息、转付农户、532 成员/公益、投资/收回）
- 往来：单位欠款、批量计提、土地流转费标准一键结转、现金/抵销核销
- 备份恢复、修改密码、导出（CSV/xlsx）、资金划转
- 双端：<992px 手机底部导航；≥992px 桌面左侧导航 + 原生下拉/居中弹窗

## 端口被占

`start.bat` 会从 8080 自动顺延到空闲端口（≤8099）；也可手动：
```bat
set APP_PORT=9000
jititaizhang.exe
```

## 环境变量（可选）

| 变量 | 默认 | 说明 |
|---|---|---|
| `APP_PORT` | 8080 | HTTP 端口 |
| `DATA_DIR` | ./data | 数据目录（本地盘，勿放网络盘） |
| `APP_BACKUP_DIR` | ./backups | 备份目录（建议不同盘） |
| `APP_KEEP_BACKUP` | 30 | 备份保留份数 |
| `APP_AUTO_BACKUP` | 1 | 每日 03:00 自动备份 |
| `APP_SECURE_COOKIE` | 空 | HTTPS 时设 1 |

## 注意事项

- 仅支持 **Windows x64**；Linux/Mac 需对应平台重新编译
- 首次运行防火墙弹窗请允许（局域网/专用网络），手机才能访问
- SmartScreen 提示“未知发布者”时选“仍要运行”（当前未签名）
- 备份目录建议与数据**不同磁盘**；数据库勿放 NFS/SMB 网络盘
- 恢复为整库快照，恢复后所有会话需重新登录
