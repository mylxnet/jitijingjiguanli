# 引导页基础数据导入设计（定稿）

> 目标：注册引导阶段提供「下载模板 → 上传导入」，一次导入三大类往来单位的基础数据，免去逐条手工录入，并自动联动建账。
> 版本：定稿 v1 —— 2026-09-09

---

## 1. 设计决策

- **范围**：仅导入「往来单位 + 各自业务属性」；**引导页最后一页 final（银行存款期初、预置科目期初、预览确认）仍由用户手工填写**，不纳入导入。
- **业务语义**：「投资公司」「再投资」= 集体经济组织资金**投资/投出**到该单位的对象（对外投资，资金流出方向）；「流转企业」= 往来/收入来源。模板字段与科目方向据此区分。

## 2. 模板结构（Excel .xlsx，3 数据页 + 1 隐藏说明页）

文件：`docs/基础数据导入模板.xlsx`

### Sheet「流转企业」→ 同名二级科目建在 土地流转费收入 / 流转管理费 下
| 列 | 字段 | 必填 | 说明 |
|---|---|---|---|
| A | 单位名称 | 是 | 保存后自动在该类型 L1 下创建同名二级科目 |
| B | 联系方式 | 否 | 同步写入单位 `contact_phone` |
| C | 流转面积(亩) | 是 | `area_mu` |
| D | 每亩年流转费(元) | 否 | `land_fee_per_mu_cents`；填了总费自动=面积×每亩 |
| E | 每亩管理费(元) | 否 | `mgmt_fee_per_mu_cents`；填了总费自动=面积×每亩 |

### Sheet「投资公司」→ 同名二级科目建在 长期投资 下
| 列 | 字段 | 必填 | 说明 |
|---|---|---|---|
| A | 单位名称 | 是 | 同名二级科目建在 长期投资 下 |
| B | 联系方式 | 否 | `contact_phone` |
| C | 投资本金(元) | 是 | `invest_amount_cents`，方向=对外投出；期初=本金 |
| D | 预期年回报率(%) | 否 | `return_rate_bps`；填了预期回报=本金×回报率 |

### Sheet「再投资」→ 同名二级科目建在 再投资 下
| 列 | 字段 | 必填 | 说明 |
|---|---|---|---|
| A | 单位名称 | 是 | 同名二级科目建在 再投资 下 |
| B | 联系方式 | 否 | `contact_phone` |
| C | 投资本金(元) | 是 | 方向=对外投出；期初=本金 |
| D | 预期年回报率(%) | 否 | 填了预期回报=本金×回报率 |

### Sheet「填写说明」（隐藏）
字段说明 + 规则提示（自动建账、同类型不重名、银行/预置科目期初不入模板、用前删示例行）。

## 3. 导入逻辑

1. 上传 xlsx → 后端解析（复用 `xuri/excelize`，导出端已在用）。
2. 逐 Sheet、逐行校验：
   - 单位名称非空；同 Sheet（同来源类型）内名称不可重复，不同类型允许同名（沿用现有规则）。
   - 面积、金额、百分比非负；金额按「元」换算为「分」落库。
3. 成功行：创建单位 → **触发联动创建同名二级科目** → 按类型写入业务属性（面积/费、投资本金、回报率、联系方式）。
   - 投出方向单位期初余额 = 投资本金（写入同名科目期初）。
4. 失败行汇总错误信息返回前端；成功与失败并存时，成功行已入库、失败行提示重填。

## 4. 前端入口（引导页 · 定稿 UI）

交互原型：`docs/onboarding-demo/index.html`（纯静态演示）

- **顶部二选一**：进入引导页先选择建账方式 ——「📥 导入 Excel 快速建账（推荐）」或「✍️ 手工逐条录入」。
- **导入模式**：
  - **不显示七步步骤条**；右上角标识为「📥 导入模式 · 自动建账」。
  - 提供「新手提示条 → 下载模板 → 拖拽/点击上传 → 类目/单位/联系/业务数据预览表 → 检校项（名称去重/格式/自动建账）」。
  - 三类单位**均可留空**（某类 Sheet 留空则跳过该类不建账，非必填）；上传即自动建同名二级科目与期初，直接进入最后一页。
- **手工模式**：
  - 显示七步步骤条（流转企业→流转企业余额→投资公司→投资公司余额→再投资→再投资余额→其他设置），右上角标识「第 X 步 / 共 7 步」。
  - 已添加单位行各有 **「🗑 删除」**，填错可删除重输。
  - 每类下方提供「本类暂无单位，跳过此步 →」，三类均可为空可跳过（对应现有 `skipThisStep` 逻辑）。

## 5. 与现有流程的对应

| 引导页原步骤 | 模板对应 |
|---|---|
| 录入单位（流转/投资/再投资） | 三个 Sheet 的单位行 |
| 填期初余额（同名科目） | 投资/再投资 = 投资本金；流转企业期初默认 0（面积/费不入科目期初，仅作应收标准） |
| final：银行期初、预置科目期初、预览 | ⛔ 不入模板，仍手工 |

## 6. 备注（待实现时确认，不影响本方案）

- 流转企业是否也需要期初余额列：当前定稿**默认期初=0**，期初余额仅用于投出方向单位（投资本金）。如需流转企业期初可在实施时追加列。
