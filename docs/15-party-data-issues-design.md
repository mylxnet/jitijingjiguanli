# 15 · 往来单位「数据缺失」提醒设计（角标 + 清单弹窗）

> 状态：已实现（v0.16.0）｜ 关联：docs/14（变更项）、`.trae/rules/project_rules.md`

## 1. 背景与目标

运营中常出现单位资料漏填：流转企业没填面积/费用、投资单位没填本金/年收益。漏填的直接后果是
**年度计提金额变成 0、应收漏登**，却没有任何提示。

目标：在侧边栏「往来单位」上给出类似微信未读数的角标，一眼看出有几个单位资料不全；
点角标能看到"某某单位缺某某数据"，并能一键跳去补录。

## 2. 判定口径（已与用户逐项确认）

以"该单位能否用于年度结转"为标准。**任一必填项为 0（含负数、空值、NaN）→ 该单位计 1**；
同一单位缺多项也只计 1。

| 类型 | 必填项（任一为 0 即"缺"） | 缺失项展示名 |
|---|---|---|
| **flow 流转企业** | `landMu`（`area_mu` 兼容）、`expectedLandFeeCents`、`expectedMgmtFeeCents` | 流转亩数、总流转费、总管理费 |
| **invest 投资公司** | `investAmountCents`、`expectedReturnCents` | 投资本金、年收益 |
| **reinvest 再投资** | 同 invest | 投资本金、年收益 |
| **other 其他** | 不参与判定 | — |

说明：
- flow 的"流转金额/管理费"按**结转总额**判定（`expectedLandFeeCents` / `expectedMgmtFeeCents`），
  即年度计提与登记欠款实际使用的金额；`每亩费`为输入项不单独判。
- 总额为界面自动派生（面积 × 每亩费），正常录入不会误报；若手动清空总额则会被判缺（符合口径）。

角标数字 = 不合格单位数之和，超过 99 显示 `99+`，为 0 时不显示角标。

## 3. 交互

1. **仅桌面**：侧边栏「往来单位」右侧红色数字角标（移动端底部 tab 不加）。
2. **点角标** → 居中弹窗，标题「数据缺失（N 个单位）」，逐行列出
   `单位名 + 类型标签` / `缺：流转亩数、总流转费`。
3. **点弹窗某一行** → 关闭弹窗 → 跳 `/contacts/parties?editParty=<id>`，
   单位列表页自动打开该单位编辑弹窗并定位到「年度数据」页，就地补录。
4. **点导航项其余部分** → 照常跳 `/contacts`（不改变现有导航行为）。

## 4. 数据与刷新

- **数据源**：复用 `GET /api/parties`（已返回全部所需字段），**前端本地计算，后端无改动**。
- **共享状态**：`useContactIssues`（模块级 ref + computed），角标与弹窗共用同一份数据。
- **刷新时机**：
  - 进入应用（`SideNav` 挂载）
  - 每次路由切换（`watch(route.path)`）
  - 单位保存后（`PartiesList`）
  - 快速记账"长期投资给公司"累计投资本金后（`RecordPopup`）
  - 引导页保存/导入后：由跳转首页触发路由刷新
- **健壮性**：
  - 并发刷新合并为一次请求（`inflight` 复用），避免路由连续切换时重复拉取；
  - 请求失败保留上一次结果，避免角标闪烁；
  - 空值判定 `blank(v) = !(Number(v) > 0)`，脏数据（负数/NaN）也计为缺。

| 后端 | — | 无改动 |

## 6. 边界与默认

- `other` 类型单位不计数。
- 单位表无启停字段，全部单位参与判定。
- 只判"缺数据"单一维度；将来若扩展（如"缺合同"），只需在 `missingFields` 增加规则。
- 角标为纯前端提示，不阻断任何操作；无缺失时完全隐藏。
