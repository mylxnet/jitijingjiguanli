# 集体台账 v0.6.0 发布说明

- 版本：**v0.6.0**（大版本定版）
- 形态：Windows x64 单可执行文件（前端已内嵌，无需安装 Go / Node / 数据库）
- 主线：科目期初 → 投资/往来重构 → 单位类型化 → 年度结转预览 → 导出

## 文件清单（拷贝到任意普通文件夹即可）

| 文件 | 说明 |
|---|---|
| `jititaizhang.exe` | 服务主程序 |
| `start.bat` | 双击启动：自动探测空闲端口（8080 被占则顺延）并打开浏览器 |

## 运行

1. 把 `jititaizhang.exe`、`start.bat` 放到普通目录（不要放系统盘受保护目录）
2. 双击 `start.bat`（或直接运行 exe）
3. 浏览器自动打开 `http://localhost:<端口>/`
4. 首次使用：登录页 →「注册组织」→ 填组织名+账号+密码 → 自动生成预置科目
   （本金=上级补助 / 长期投资 / 经营收入 / 分配与支出）

> 服务启动会在同目录自动创建 `data\`（数据库）与 `backups\`（备份）。
> 旧数据升级：启动自动执行迁移 007/008/009，无需手工操作。

## 主要变化（v0.5.0 → v0.6.0）

### 记账模型
- 资金划转/资产资金池弃用，投资/收回改为收支流水：
  - 投资给公司 = 银行减少，记入「长期投资 / 公司」，自动建同名往来单位（投资公司）
  - 收回投资 = 银行增加，记入「上级补助」
- 科目期初：二级科目可填期初余额，余额=期初+发生额
- 快速记账新增「支出管理费」（记入分配与支出/管理费支出）

### 往来单位
- 单位分三类：**流转企业 / 投资公司 / 其它单位**（编辑可改）
- 投资公司资料含**只读投资金额**（=长期投资同名公司累计投出，自动同步）
- 流转企业填**年度流转费**；投资公司填**年度应得分红**
- 联系电话、流转面积（亩）进单位资料
- 单位详情为弹窗（蓝色主色），展示全部信息，标准可就地修改

### 年度结转（原批量计提）
- 单位详情/年度标准填好金额 → 往来页「年度结转」→ 选年度 → **生成预览**
  （列出各单位/类别/金额，标注“将新增 / 已存在跳过”）→ 确认才生成应收
- 结转数据为分年度快照不可直接改；未收款的应收可作废后重新结转

### 界面
- 登录页大字=组织名、小字=集体经济管理系统
- 桌面左侧导航：看板/流水/汇总/往来/记账 + 底部 设置/退出
- 看板新增“最新流水”
- 往来页三 banner：欠款总计 / 流转费欠款 / 投资收益欠款，点击筛选企业
- 往来导出 Excel：单位基本情况、欠款明细

## 验证建议
1. 建/编辑单位：类型、电话、面积、年度标准
2. 记一笔“投资给公司”→ 该公司详情投资金额自动增加
3. 年度结转：生成预览 → 确认 → 应收单出现 → 收款核销
4. 往来导出：单位基本情况 / 欠款明细
