# 集体台账 · 操作手册（记账员版）

> 面向每天记账的村集体操作者。配套：开发技术文档 `04-dev-manual.md`、发布说明 `release-v0.5.0.md`。
> 本手册正文以 v0.5.0 为底，v0.23.0 复核并更新了「入门 / 忘记密码 / 常见报错」三处口径；更新的功能界面见 `19-新用户快速入门.md`。

## 1. 入门

### 1.1 打开与注册

1. 电脑浏览器访问 `http://localhost:8080`（Docker/NAS 部署时换成映射的端口；本机开发态另有 `http://localhost:5173`）。
2. 没有账号 → **仅当系统里还没有任何用户时**登录页才会出现「注册组织」入口（注册一个组织后该入口自动隐藏）：
   - 组织名称（如 XX村）
   - 账号（登录名，全局唯一）
   - 密码（至少 6 位，需输两次）
3. 注册成功即自动登录，系统已生成**预置科目**（本金、对外投资、经营收入、分配与支出等），可直接记账。

> 一个账号绑定一个组织，组织之间数据完全隔离。
> 输错时错误提示就显示在对应输入框的**同一行右侧**（如「请填写组织名称」「两次输入的密码不一致」），不会把表单挤动。

### 1.2 桌面 / 手机

- 电脑宽屏（≥992px）：左侧导航（看板/流水/汇总/往来/设置），下拉为鼠标友好的原生菜单，弹窗居中。
- 手机窄屏：底部 5 个页签，下拉为移动端弹层。

## 2. 首页看板

打开系统默认进「看板」，一眼看到：

| 卡片 | 含义 |
|---|---|
| 银行存款 | 银行里现在有多少 |
| 资产类 | 投到外面的钱（如对外投资某公司）合计 |
| 待收欠款 | 各往来单位还欠多少 |
| 净资产 | 银行+资产−待付口径之外的总权益（收付实现后归属本村的部分） |
| 本年收益（到账） | 今年已到账的收入合计 |

下方「欠款明细」列最近谁欠什么；点行跳往来页。

底部绿色大按钮「**记一笔**」随时打开记账。

## 3. 记一笔（普通记账）

1. 首页点「记一笔」→ 选「普通记账」。
2. 选 收入/支出。
3. 填：日期（默认今天）、摘要（可空）、科目、金额。
4. 保存。

- 科目只出现「权益」类（记收入/支出的去向来源）。
- 若想记“钱投到外面/收回来”，请走科目页「资金划转」，不走收支。

## 4. 记一笔（快速记账）

适合固定业务，自动入账：

1. 点「记一笔」→ 切到「快速记账」。
2. 选业务（10 个模板）：
   - 收上级财政补助
   - 收到投资收益/分红
   - 收到土地流转费（选单位后**自动冲该单位欠款**；无欠款则直接记收入）
   - 土地流转服务费收入
   - 拨付土地流转费给农户
   - 银行存款利息
   - 532-成员分配发放
   - 532-公益支出
   - 投资给公司（需先选公司资产科目）
   - 收回投资
3. 需要时选公司/单位、填金额 → 保存（自动入账）。

> 依赖预置科目名自动定位；若提示“缺少科目：XX”，说明该科目被改名/删除，去科目页核对。

## 5. 科目管理（设置 → 科目管理）

- 一级科目是**分组容器**（只填名称）。
- 二级科目类型只有两种：
  - **权益**：记收支用的科目（补助、收益、分配、公益、转付农户等），收增支减；
  - **资产**：投到银行外的钱（对外投资某公司），进出只能走「资金划转」。
- 新增二级时可点「选单位填名称」快捷带出往来单位名。
- 已被引用的科目不能删除，只能停用；停用后不再出现在记账下拉。
- 页面提供：科目间转账（权益科目间调剂/结转）、资金划转（投资/收回）。

## 6. 往来与欠款（往来 tab）

1. 对象都是「往来单位」。
2. 新增单位 → 点进详情 → 「登记应收」（流转费/投资收益/其他，可预设收款入账科目）。
3. 批量计提：
   - 「批量计提」弹层 → 批量计提页签：填年度/事由 + 逐行单位+金额 → 保存（同年同类自动防重）；
   - 「流转费标准」页签：为单位预存年度流转费金额 → 列表可启停 →「一键结转 2026 年度流转费」自动生成应收。
4. 收款/抵销：未结清应收单点「收款/抵销」：
   - 现金入账：自动记银行收入 + 冲该单位欠款；
   - 抵销：用一笔分红/福利支出流水冲应收（不产生现金流水）。
5. 核销记录可展开查看并作废（作废现金核销会连带作废对应银行收入流水）。

## 7. 汇总与导出（汇总 tab）

- 顶部月份可切换。
- 资金构成：银行存款 / 资产类 / 净资产 / 总资产。
- 科目余额树：一级行=子项合计；点二级科目可看该科目某月流水。
- 「导出」：收支汇总 / 科目余额表 × Excel / CSV；导出文件已带格式，可直接打印。

## 8. 设置

- 资金账户：填写**银行存款期初余额**（建账时点的银行余额）→ 保存。
- 科目管理入口。
- 修改密码：原密码+两次新密码。
- 备份与恢复：
  - 「立即备份」随时生成快照；自动备份每日 03:00，保留 30 份。
  - 恢复=整库回到某快照（所有组织都会回退），完成后需重新登录；恢复前建议先备份。

## 9. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 登录报“账号或密码错误” | 提示直接显示在密码框同一行右侧。先核对账号口令；确属忘记 → 登录页点「忘记密码？」进入重置页，密码会被重置为默认口令 `admin888`（重置的是系统里最早注册的那个账号），登录后请立即到「设置 → 修改密码」换掉 |
| 提示“请先登录”但我在登录页 | v0.23 已修复：登录/注册/重置密码的失败不再被误报成「请先登录」，现在显示的是服务端的真实原因。若仍见该提示，说明是会话到期，重新登录即可 |
| 端口被占用 | 用 `scripts\start-windows.bat`（同目录放 `jititaizhang.exe`）会自动在 8080~8099 间挑空闲端口并打开浏览器；或自行设 `APP_PORT=端口` 后重启服务 |
| 手机访问不了 | 检查同一局域网、防火墙允许服务端口 |
| 科目改名后快速记账报“缺少科目” | 改回默认名或在科目页新增同功能科目 |
| 记支出时科目下拉没有想要的科目 | 去科目管理新增「权益」二级科目 |
| 想查某单位还欠多少 | 看板欠款明细或往来页点该单位 |
| 数据安全 | 备份目录放到与数据不同的盘；数据库目录别放网络盘 |

## 10. 重要口径提醒

- **到账才算收益**：没收到钱，往来显示“待收”，不计收益/资产。
- **532**：只是按 5:3:2 拆成 再投资/成员分配/公益 去记账，系统不另建“方案单”，查流水按摘要/科目筛选即可。
- 每笔流水可作废/撤销并留痕，科目只能停用，账目可追溯。
