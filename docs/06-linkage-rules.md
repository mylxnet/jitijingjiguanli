# 数据联动规则文档

> 本文档记录系统中的所有数据联动规则，已与用户逐项确认并实现。

---

## 一、记账类联动

### 1.1 记一笔（收入/支出）

| 操作 | 联动影响 |
|------|----------|
| 记一笔收入 | 银行存款 + / 科目余额 + |
| 记一笔支出 | 银行存款 - / 科目余额 -（校验余额 ≥ 0，不足时拒绝） |
| 编辑流水 | ❌ **已禁用**，流水只能作废，不能修改金额/摘要/科目 |
| 作废流水 | 回滚联动：银行存款和科目余额回退至操作前状态，等于该业务未发生 |

### 1.2 快速记账（10 模板）

| 模板 | 联动影响 |
|------|----------|
| 收上级财政补助 | 收入 → 银行存款 + / `上级补助`科目余额 + |
| 收到投资收益/分红 | 收入 → 银行存款 + / `投资收益`L1 下单位名子科目 + / 该单位应收已收+、待收-（自动核销） |
| 收到土地流转费 | 收入 → 银行存款 + / `土地流转费收入`L1 下单位名子科目 + / 该单位应收已收+、待收-（自动核销） |
| 收到流转管理费 | 收入 → 银行存款 + / `流转管理费`L1 下单位名子科目 + / 该单位应收已收+、待收-（自动核销） |
| 拨付流转费给农户 | 支出 → 银行存款 - / `土地流转费-转付农户`科目余额 - |
| 支出管理费 | 支出 → 银行存款 - / `管理费支出`科目余额 - |
| 银行存款利息 | 收入 → 银行存款 + / `其他收入`科目余额 + |
| 532-成员分配发放 | 支出 → 银行存款 - / `成员分红`科目余额 - |
| 532-公益支出 | 支出 → 银行存款 - / `公益支出`科目余额 - |
| 长期投资给公司 | 支出 → 银行存款 - / 选中公司子科目余额 -（投资） |
| 收回投资 | 收入 → 银行存款 + / `待投资`科目余额 + |
| 532-再投资 | 支出 → 银行存款 - / `再投资`L1 下单位名子科目余额 - |

## 三、往来/应收类联动

### 3.1 应收单

| 操作 | 联动影响 |
|------|----------|
| 登记应收 | ⬜ **下步开发计划**，本期暂不实现 |
| 批量计提 | 批量创建应收单，不产生资金变动 |
| 年度一键结转 | 按配置自动生成年度应收单，不产生资金变动 |

### 3.2 收款核销

| 类型 | 联动影响 |
|------|----------|
| 现金收款（cash） | 应收单已收 + / 待收 - → 银行存款 + → 创建收入流水 |
| 抵销（offset） | 应收单已收 + / 待收 -，不产生银行存款变动，不创建流水 |
| 作废现金核销 | 核销记录状态 normal → voided → 应收单已收回退、待收恢复、状态回退（closed→open 或保持 partial）→ 该单位 outstandingCents 重新汇总 → 对应的收入流水同步作废（银行存款回退） |
| 作废抵销核销 | 核销记录状态 normal → voided → 应收单已收回退、待收恢复、状态回退 → 该单位 outstandingCents 重新汇总，不动银行存款和流水 |

### 3.3 新增单位 → 自动创建科目

| 单位类型 | 联动创建科目 | 父科目 |
|----------|-------------|--------|
| 投资类 (`invest`) | 创建 1 个二级科目 | 长期投资（id:2） |
| 再投资 (`reinvest`) | 创建 1 个二级科目 | 再投资（id:3） |
| 流转企业 (`flow`) | 创建 2 个二级科目 | 土地流转费收入（id:6）+ 流转管理费（id:7） |
| 长期投资 (`longterm`) | 不创建 | — |
| 其它 (`other`) | 不创建 | — |

**科目名称** = 单位名称

**创建时机**：新增单位时，立即执行联动，同步创建二级科目（包括引导页建公司）

**重名校验**：名称 + 类型一致才判重，不同类型允许同名。模糊匹配提示用户

**编辑/删除**：❌ **已禁止**。单位名称/类型不得编辑，单位不得删除

## 四、投资类联动

### 4.1 532 分配

| 操作 | 联动影响 |
|------|----------|
| 创建分配方案 | 保存再投资/分红/公益金额分配方案，不产生资金变动 |
| 执行分配（再投资） | 走 `532-再投资` 快速记账模板 → 银行存款 - / `再投资`L1 下单位名子科目余额 - |
| 执行分配（成员分红） | 走 `532-成员分配发放` 快速记账模板 → 银行存款 - / `成员分红`科目余额 - |
| 执行分配（公益支出） | 走 `532-公益支出` 快速记账模板 → 银行存款 - / `公益支出`科目余额 - |
| **方案锁定** | 分配方案执行后（产生任何一条流水），该方案即锁定不可编辑。弹窗显示只读视图 |

## 五、流转管理类联动

### 5.1 土地流转费

| 操作 | 联动影响 |
|------|----------|
| 登记流转费应收 | 同 3.1 登记应收（⬜ 下步开发计划） |
| 收到流转费 | 走快速记账 `收到土地流转费` 模板 → 银行存款 + / `土地流转费收入`L1 下单位名子科目 + / 应收自动核销 |
| 拨付农户 | 走快速记账 `拨付流转费给农户` 模板 → 银行存款 - / `土地流转费-转付农户`科目余额 - |

### 5.2 管理费

| 操作 | 联动影响 |
|------|----------|
| 登记管理费应收 | 同 3.1 登记应收（⬜ 下步开发计划） |
| 收到管理费 | 走快速记账 `收到流转管理费` 模板 → 银行存款 + / `流转管理费`L1 下单位名子科目 + / 应收自动核销 |
| 管理费支出 | 走快速记账 `支出管理费` 模板 → 银行存款 - / `管理费支出`科目余额 - |

## 六、合同类联动

| 操作 | 联动影响 |
|------|----------|
| 上传合同 | 文件保存至内存（生产态存 OSS/磁盘），关联到往来单位，不影响资金 |
| 删除合同 | 删除文件记录，不影响资金 |

---

## 七、设置/引导页类联动

### 7.1 引导页余额

| 操作 | 联动影响 |
|------|----------|
| 引导页输入银行期初 | 写入 `SETTINGS.bankOpeningBalanceCents`，同步看板银行存款 |
| 引导页输入科目余额 | 写入对应二级科目的 `openingBalanceCents`，同步科目余额 `balanceCents`（`balanceCents = openingBalanceCents`） |

### 7.2 设置页

| 操作 | 联动影响 |
|------|----------|
| 保存期初余额 | 银行存款期初变 → 银行存款当前余额变 → 看板净资产变 |
| 修改密码 | 无联动 |

---

## 八、备份/恢复类联动

| 操作 | 联动影响 |
|------|----------|
| 立即备份 | 生成备份记录 |
| 恢复备份 | 替换所有数据 → 强制重新登录 |

---

## 九、操作日志

| 操作 | 联动影响 |
|------|----------|
| 所有修改型操作 | 记录操作日志（字段级 old→new，仅保留 48 小时，自动清理超期记录） |
