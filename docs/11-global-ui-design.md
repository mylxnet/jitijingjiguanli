# 全局 UI / 视觉与系统级约定

> 记录近一轮迭代确立的、跨模块通用的界面与系统约定。新增页面/组件时优先遵循本文，保持一致观感。

---

## 1. 统计卡淡色背景规范

各主要页面顶部统计卡统一使用**淡色背景**（去细边框、保留圆角），且**同页内各卡互不相同**，参照收支总览页风格：

| 页面 | 统计卡 | 配色（淡） |
|---|---|---|
| 汇总/收支总览 | 银行存款/资产/净资产/总资产 | 淡蓝 / 米黄 / 淡绿 / 淡靛 |
| 投资管理 | 各套统计卡 | 淡蓝 / 淡青 / 淡紫 / 淡黄 |
| 流转管理 | 各套统计卡 | 淡米黄 / 淡绿 / 淡红 / 淡蓝 |
| 应收（三页共用） | 应收合计/已收/未收/收缴率 | 淡紫 / 淡绿 / 淡红 / 淡蓝 |
| 往来单位概览 | 单位总数/本年应收/本年已收/本年未收 | 淡紫 / 淡黄 / 淡蓝 / 淡红 |

- 数值原有着色保留（如未收红、已收绿等语义色不变）。
- 淡色背景通过 `:nth-child(n)` 依次分配，避免页面间配色重复可适当错位。

## 2. 概览/统计卡图标扁平化（方案 C）

- 放弃「彩色圆形底 + emoji」的图标组合（彩色底 + emoji 自带铸色彩，视觉偏重）。
- 改用**扁平灰色 Vant 线性图标**，置于**半透明白色圆角底**上，与淡色卡面融合（示例 `Overview.vue .ov-fi`）。
- 图标配色：中性灰（如 `#7b8794`），字号约 22px，圆角底 40×40 圆角 10px、背景 `rgba(255,255,255,0.65)`。
- 本方案经用户选中并**保持现状**，后续统计卡图标统一按此风格处理。

## 3. 主题色与主按钮

- 全局主题玉绿主色 `--jade: #1f5c48`（见 `styles/theme.css`），用于导航高亮、类型按钮等。
- **快速记账弹窗内**的 primary 主按钮（「快速记账」mode 切换、底部「提交」）另做**局部调浅**（不改全局 `--jade`），最终定为：
  - 背景 `#e5f5f4`（极淡青绿），文字深绿 `#1f5c48`（保证浅底可读）；hover 背景 `#d3eeee`、文字 `#143d30`。
  - 弹窗内「新建单位」链接绿色也随之调为 `#07c160`。
  - 原则：涉及全局主题色的加深/调浅，默认**只做局部覆盖**，避免影响全站其它主色元素，除非用户明确要求改全局。

---

## 4. 浏览器标签页标题

- 统一为 **`{注册组织名}集体经济管理平台`**。
- 实现：`router/index.ts` 全局 `afterEach` 中设置 `document.title`；已登录取 `localStorage.jt_org_name`，未登录仅显示 **`集体经济管理平台`**。
- `index.html` 默认标题亦为「集体经济管理平台」，避免首屏闪旧标题。

---

## 5. 其他跨模块约定

- **应收状态语义色**：未收=红、部分收=橙、结清=绿（状态标签圆角胶囊 + 进度条同色随状态）。
- **「余」类差额红字**：532 类目卡等「总计/已支/余」场景，仅「余」字与差额金额用红字（`.rd`），总计、已支保持默认色。
- **按钮配色偏好**：系统重置于弹窗一律用默认白/灰样式，不使用 danger 红色（用户偏好）。
- **金额数值**：统一 `tabular-nums`（`font-variant-numeric: tabular-nums`）保证对齐。
