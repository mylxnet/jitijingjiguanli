## 1. 问题清单（修复前）

| # | 现象 | 根因 | 位置 |
|---|---|---|---|
| 1 | 密码输错时提示「请先登录」，看不到真实原因 | `request()` 见到 401 一律走会话失效分支：触发 `onUnauthorized()` 并把服务端 message 换成「请先登录」。而登录/注册/重置这些**公开认证接口**返回 401/400 是业务结果，不是会话失效 | `web/src/lib/http.ts`（旧 52-57） |
| 2 | 提示「账号或密码错误」出现/消失时按钮上下跳 96px | 错误条是插在字段与按钮之间的独立块，会把整张卡片撑高 | `Login.vue`（旧 28）、`Register.vue`（旧 43） |
| 3 | 认证页整页可上下滚动，点提交时页面跳动 | `.login-page`/`.register-page` 重复声明 `min-height:100vh` + `padding:24px`，而外层 `.auth-wrap`（`App.vue`）已经做了同一件事 → 总高 = 100vh + 48px | `Login.vue`、`Register.vue` 样式块 |

## 2. 修复方案

### 2.1 401 分流（问题 1）

`http.ts` 增加公开认证路径白名单，只有非白名单的 401 才当作会话失效：

```ts
const PUBLIC_AUTH_PATHS = ['/auth/login', '/auth/register', '/auth/reset-password']
...
if (res.status === 401 && !PUBLIC_AUTH_PATHS.includes(path)) {
  if (onUnauthorized) onUnauthorized()
  throw new Error('请先登录')
}
// 白名单路径落到下方的通用错误分支：透传服务端 { error: { code, message } } 的 message
```

- 白名单写的是**去掉 `/api` 前缀后的 path**，与 `request()` 内部拼接一致。
- `/auth/registration-status` 不必列入：`store.ts` 用裸 `fetch` 查询，不走 `request()`。
- 后端返回体口径不变：失败 `{"error":{"code","message"}}`，成功 `{"data":...}`。

### 2.2 错误提示与输入框同行（问题 2）

沿用同一套模式，登录页与注册页一致：

| 手段 | 作用 |
|---|---|
| `van-form :show-error-message="false"` | 关掉 Vant 追加在字段下方的默认错误消息（`.van-field__error-message`），这是撑高的元凶 |
| `van-form @failed="onValidateFailed"` | 校验失败时拿到 `errors[0].name`，决定提示挂在哪一行 |
| 每个 `van-field` 的 `#extra` 插槽 | Vant 把 Field 的 `extra` 透传给 Cell 的 `extra`，渲染在 `.van-cell` 最右侧**同一行** |
| `errorField` + `showError(field, msg)` | 一个 ref 决定挂载行，另一处 `error` 存文案 |
| `.field-error{line-height:inherit; white-space:nowrap; max-width:140px; ellipsis}` | 行高继承 `.van-cell` 的 24px，出现/消失都不改变行盒高度；超长文案省略号 + `:title` 全文 |
| `watch(字段们, 清空 error, {flush:'sync'})` | 输入即清提示。**必须 `flush:'sync'`**：登录失败时会先清空密码再写提示，用默认 `pre` 队列会因清空回调晚于赋值而把提示抹掉 |

提示落点约定：

| 页面 | 事件 | 落点 |
|---|---|---|
| 登录 | 必填校验失败 | 失败的第一个字段行 |
| 登录 | 账号或密码错误（401） | 密码行 |
| 注册 | 必填/格式校验失败 | 失败的第一个字段行 |
| 注册 | `USERNAME_TAKEN`（409/400） | 账号行 |
| 注册 | `REGISTRATION_CLOSED` 及其他异常 | 组织名称行（整单失败，不归属某一字段） |

### 2.3 页面容器去重复（问题 3）

`.login-page` / `.register-page` 只保留 `width:100%` + flex 居中，删除 `min-height:100vh`、`padding:24px` 与 `background`（底色由 `body`/`#app` 的 `--paper` 提供）。居中与留白统一由 `App.vue` 的 `.auth-wrap` 负责。
