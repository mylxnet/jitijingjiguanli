## 2. 快速记账模板扩展

### 2.1 新增模板清单

`QuickBiz` 配置（`RecordPopup.vue`）新增两个「其他」分组业务：

```ts
{ key: 'otherIncome', label: '收到其他收入', dir: 'income', catName: '其他收入', defaultNote: '收到其他收入', manualNote: true, group: '其他' },
{ key: 'otherPay',    label: '拨出其他收入', dir: 'expense', catName: '其他收入', defaultNote: '拨付其他收入', manualNote: true, group: '其他' },
```

| 业务 | 方向 | 入账科目 | 摘要 |
|---|---|---|---|
| 收到其他收入 | 收入 | 其他收入 +，银行存款 + | 默认「收到其他收入」，可改 |
| 拨出其他收入 | 支出 | 其他收入 −，银行存款 − | 默认「拨付其他收入」，可改 |

- **不选单位**（`needParty` 未置）：不弹往来单位下拉，`partyId` 为空。
- 账务：走普通收支 `txn`，靠科目类型（`otherIncome` 收入 / `expense` 支出）驱动银行存款、科目余额、净资产同步增减，作废即可整体回滚。
- 两个模板共用「其他收入」权益科目（按名称动态解析，见 2.3 的 `findEquityCat`），不新增迁移。

### 2.2 可编辑摘要：`manualNote` 机制

- `QuickBiz.manualNote: true` 表示该业务**需要用户输入摘要**，弹窗显示「摘要」`van-field`（默认值 = `defaultNote`，可修改）。
- 预填时机有**两处**，保证任何入口进入都带默认文案：
  - 切换业务 `onQuickBizChange()`：若 `b.manualNote` → `quick.note = defaultNote`；
  - 打开弹窗 `openRecord()`：若初始业务 `manualNote` → 同样预填。
- 提交口径 `saveQuick()`：`manualNote` 业务取 `quick.note.trim() || fillNote(defaultNote)`（用户留空则回退模板默认，不强制）。

### 2.3 「待投资」直减（`recordToPool`）方案与技术逻辑

**背景**：业务「其他财政性收入投资给公司」属对外投资支出（资金投出），需同时减少银行存款与「待投资」结余。
曾用**科目间结转**方案（`transfer`/`transfer_leg` + `txn_id` 联动，迁移 019），因产生额外「待投资结转」科目且破坏直觉，**已弃用**。

**最终方案**：主流水**直接记支出到「待投资」权益科目**，一笔即同时反映 银行−、待投资−、长期投资不变；不作任何结转、不产生新科目。

```ts
{ key: 'otherInvest', label: '其他财政性收入投资给公司', invest: true, dir: 'expense',
  catName: '待投资', recordToPool: true, defaultNote: '其他财政性收入投资给公司', group: '资金类' }
```

`saveQuick()` 的分支逻辑（仅列与本期相关）：
1. `biz.recordToPool === true`
   - 用 `findEquityCat('待投资')` 按名称动态定位权益科目（`kind==='equity' && name==='待投资'`，不硬编码 ID）；
   - `categoryId = 待投资.id` → `POST /transactions {direction:'expense', categoryId: 待投资}`；
   - 一笔支出 = **银行存款−、待投资−**，净资产−（对外投资减少待投资结余，无需凭证支持余额为正）。
2. 旧「长期投资给公司」（`invest`、无 `recordToPool`）分支：`categoryId = companyId`（按公司建科目），行为保持不变。
3. **公司投资额展示**（非账务权威，仅对账口径）：投资任一公司后 `syncInvestedAmount(amount)`，把该往来单位 `investAmountCents += amount`（`PUT /parties/:id`），与投资页投资金额口径一致，便于对账；科目余额始终为权威口径。

**为什么不再用 transfer**：账务要的是「待投资结余减少 + 钱确实流出」，而结转方案在权益科目内部转移，虽不动银行却凭空造出「待投资结转」科目、语义晦涩；直记支出更贴近「投资投出了待投资的钱」这一事实，作废回滚也只需作废一笔主流水。

> 遗留：旧方案已建空科目「待投资结转（id=24，bal=0）」，新方案不再使用，待用户确认是否删除（未删）。

### 2.4 验证口径（真实 Go 后端 + 真实库）

| 检查项 | 结果 | 证据 |
|---|---|---|
| 收到其他收入 | ✅ | txn income，其他收入 +、银行 + |
| 拨出其他收入 | ✅ | txn expense，其他收入 −、银行 − |

## 3. 往来单位删除（DeletePartyDialog）

- **入口**：设置页「高级设置」→「删除单位」（`SettingsPage.vue`）。
- **实现**：`DeletePartyDialog.vue` 弹窗列出单位，每行后端返回可否删除。
  - 后端判定并回填 `deleteBlockReason`（如存在流水/应收/其他业务关联则不可删）→ `DELETE /parties/:id`；
  - 前端仅对无关联单位放行删除，成功即 `api.del('/parties/:id')`，并同步移除该单位同名科目（若有）。
- **保留约束**（承继既有规则）：单位名称、类型仍不可编辑；仅在确认无业务关联时可删除。
- **引导页**复用同一 `api.del('/parties/:id')` 删除未入账单位。
